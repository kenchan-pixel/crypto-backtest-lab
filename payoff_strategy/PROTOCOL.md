# Payoff-aware Sequence Strategy — frozen 2026-09-20

## Motivation
Previous studies repeatedly found patterns that increased the probability of a +1% move but still lost money after costs. This experiment changes the target from directional classification to **expected after-cost spot return**. It is a new objective, not a threshold tweak to rescue a failed classifier.

## Inputs
Reuse the exact causal sequence-event table generated by the frozen Sequence Strategy study:
- market state before catalyst;
- catalyst type/family;
- 6h confirmation;
- exact next-minute entry/24h exit return after confirmation.

No future outcome is a feature. No forward-collected news is used in historical fitting because its coverage begins only on 2026-09-20.

## Chronology
- 2024: fit model and freeze score threshold.
- 2025: validation.
- 2026 through 2026-09-14: reused historical audit.
This history is not blind OOS.

## Fixed model
Per coin:
HistGradientBoostingRegressor(
- max_iter=100
- learning_rate=0.05
- max_leaf_nodes=7
- max_depth=3
- min_samples_leaf=30
- l2_regularization=10
- early_stopping=False
- random_state=20260919
)

Categorical inputs are one-hot encoded using the same frozen sequence schema. Target is the single-event **base-cost net return** from the next-minute entry after 6h confirmation to the fixed 24h exit.

No parameter sweep and no model selection.

## Frozen signal threshold
For each coin, after fitting on 2024 only:
- compute model predictions on the 2024 training events;
- threshold = max(0, 90th percentile of those predicted returns).

The threshold is frozen before evaluating 2025/2026. This creates an approximately top-decile expected-payoff filter without tuning against validation results.

If multiple catalysts produce signals with the same entry time, keep only the highest predicted expected return. One spot position per coin; ignore all new signals until the fixed 24h exit. No same-minute re-entry.

## Costs
Base per side: 0.10% fee + 0.05% adverse slippage.
Stress per side: 0.15% fee + 0.15% adverse slippage.
No leverage, shorting or funding-income assumption.

## Required outputs
For 2025 and 2026:
- raw signal events;
- executed non-overlapping trades;
- compounded base/stress return;
- trade count, win rate, mean, median, profit factor;
- hourly-observable max drawdown;
- best-trade-removed compounded return;
- predicted-vs-realized rank correlation (descriptive).

## Statistical audit
Use the executed base-cost trade returns.
2026 one-sided weekly-cluster bootstrap tests mean trade return > 0 with 1,999 replicates, fixed seed 20260919. Holm correction across 2 coins. 28-day grouping diagnostic only.

## Candidate gate
A coin can be promoted only to **payoff-aware research candidate** if:
2025:
- >=30 executed trades;
- base compounded return >0;
- stress compounded return >0;
- profit factor >1.10;
- base best-trade-removed compounded return >0.

2026:
- >=15 executed trades;
- base compounded return >0;
- stress compounded return >0;
- profit factor >1.10;
- base best-trade-removed compounded return >0;
- corrected weekly-bootstrap p<0.05.

Otherwise no candidate. Do not alter percentile, hold time, model or features after seeing results.

## Interpretation
A surviving result is still retrospective research only. It must be frozen for forward monitoring on genuinely new Event + Regime data before any live consideration.
